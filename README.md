## 项目简介

本项目是一个基于物联网应用的微信小程序。系统通过 **OneNet 提供的 API** 与硬件设备进行数据交互，实现设备的数据采集、控制与监测。后端部分使用 **Flask 框架** 搭建，并结合数据库实现数据持久化存储与业务逻辑处理，为前端小程序提供 RESTful API 服务。

### 技术栈说明
- **前端**：微信小程序
- **物联网平台**：OneNet API（设备接入与数据交互）
- **后端**：Flask（Python）
- **数据库**：关系型数据库（如 MySQL / SQLite，根据实际使用情况填写）

### 功能概述
- 设备数据的实时获取与展示
- 支持设备远程控制操作
- 历史数据存储与回溯查询
- 通过 Flask 后端提供统一接口服务
